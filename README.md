## 🌉 Connections to Other Fields (Conceptual Bootstrapping)

This project is not merely a computer vision exercise; it holds three interdisciplinary connections for me:

1. **Telecommunications (MSc):** The confusion matrix is ​​analogous to the Bit Error Rate (BER) in MIMO systems; 
Cross-Entropy is equivalent to Cross-Correlation in signal detection.

2. **Governance (PhD):** The "needs_review" decision serves as a microcosm of designing
Human-in-the-loop decision-making systems.

3. **Intellectual Development:** Designing a confidence threshold is akin to
designing an educational intervention—determining when to let a child be and when to intervene.
